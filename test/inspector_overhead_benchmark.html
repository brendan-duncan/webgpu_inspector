Measures the main-thread cost of the page's own WebGPU calls, which is what the inspector's per-call instrumentation adds to. GPU work is deliberately trivial so the number reflects CPU overhead, not rendering.

Query parameters: ?inspect=1 loads the built inspector from extensions/chrome/webgpu_inspector.js before any WebGPU call; ?stacks=1 also turns on object creation stacktraces. Load without parameters for the uninstrumented baseline.

Stats reset automatically when the workload or iteration count changes, and the first 30 frames of each run are discarded as warm-up.
